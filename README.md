# 📚 Wiki: Repositório Java-CursoemVideo

Este repositório no GitHub, criado por Heitor Berg, é dedicado a materiais e resoluções de exercícios do **Curso de Java Básico do Curso em Vídeo**, ministrado pelo Professor Gustavo Guanabara. ☕

Este repositório serve como um recurso prático para acompanhar e revisar os conceitos fundamentais da linguagem Java, desde sua história até a criação de programas básicos e o uso de estruturas de controle e dados.

## 🌟 Conteúdo Esperado do Repositório:

O repositório `Java-CursoemVideo` provavelmente contém exemplos de código, exercícios e soluções que abordam os tópicos essenciais do Java Básico, seguindo a estrutura do curso oficial do Curso em Vídeo:

* **Introdução ao Java:**
    * História do Java e sua importância no mercado.
    * Como o Java funciona (JVM, JRE, JDK).
    * Instalação e configuração do ambiente de desenvolvimento (JDK).
* **Primeiros Passos em Java:**
    * Estrutura básica de um programa Java.
    * Sintaxe fundamental da linguagem.
    * Criação do seu primeiro programa "Olá, Mundo!".
* **Fundamentos da Linguagem:**
    * **Tipos Primitivos:** Manipulação de dados (inteiros, reais, booleanos, caracteres).
    * **Operadores:** Aritméticos, lógicos, relacionais e de atribuição.
    * **Entrada de Dados:** Leitura de informações do usuário.
    * **Classe Math:** Funções matemáticas úteis.
* **Estruturas de Controle:**
    * **Condicionais (`if`, `else`, `else if`, `switch`):** Tomada de decisões no código.
    * **Laços de Repetição (`for`, `while`, `do-while`):** Execução repetida de blocos de código.
* **Estruturas de Dados Simples e Métodos:**
    * **Vetores (Arrays):** Armazenamento de coleções de dados.
    * **Métodos (Funções):** Criação de blocos de código reutilizáveis.
* **Introdução a Interfaces Gráficas (GUI):**
    * Primeiros passos com bibliotecas como Swing e/ou JavaFX para criar janelas e componentes visuais.
* **Exercícios Práticos:**
    * Série de problemas resolvidos para fixação do conteúdo.

## 💡 Como Usar este Repositório:

Este repositório é um excelente complemento para quem está estudando Java com o Curso em Vídeo ou deseja revisar os conceitos básicos:

* **Acompanhamento de Aulas:** Utilize os códigos como referência enquanto assiste às aulas teóricas e práticas.
* **Prática Ativa:** Tente resolver os exercícios por conta própria e depois compare suas soluções com as do repositório.
* **Referência Rápida:** Consulte os exemplos para relembrar a sintaxe e a aplicação de conceitos específicos.
